# 工作界面更新（2026-09-27）

新版目录：`release-workspace-v2/win-unpacked`，本地服务协议 5。

从托盘完整退出旧 Sakuya，再打开项目根目录的 `Sakuya Desktop.lnk`。只关闭窗口通常仍会保留托盘服务。用户数据继续使用原来的 `.data`，无需重新注册或重新配置供应商。

## 使用方式

- 直接进入工作首页，不再提供聊天/工作模式切换。
- 输入框左下选择「每次询问」「帮我批准」「自动批准」。默认「帮我批准」允许读取，修改日历/任务、同步或运行实验前等待确认。「每次询问」还会在资料检索轮次和读取工具前确认。「自动批准」用于当前对话或研究任务。工具执行结果会保留，批准后恢复执行不会重复已完成的工具操作；拒绝后不执行对应操作。
- 输入框右下打开模型弹层；点击弹层中的模型名称打开供应商配置的模型列表，滑条可调整默认/低/中/高四档。只向标记支持思考强度的模型发送对应参数。
- 左侧竖线打开聊天记录，右侧竖线打开任务清单、日历或深度研究。两条线均离窗口边缘留有鼠标操作空间。
- 打开右侧功能后，拖动中间分隔条调整占比（30%–70%），偏好按账号保存。也可聚焦分隔条后用左右方向键、Home、End 调整。窄屏改为上下排列。
- 原有常驻模型行和「任务与日历 MCP / 打开日历」提示行移除，工具仍按所选权限模式执行。
- 设置按钮旁切换中文/English，界面立即更新并保留语言选择；用户输入、模型名称和回复正文不会被翻译替换。

## 账号兼容

- 新注册必须填写用户名、邮箱和密码；用户名为 3–32 位字母（含中文）、数字、下划线或短横线，忽略大小写保证唯一。
- 可通过用户名或邮箱配合密码登录，人机验证仍在桌面内部完成。
- 旧账号首次升级时生成用户名：使用邮箱前缀，移除不支持的字符，重名添加数字后缀。右上角显示用户名，原邮箱仍可登录。
- 邮箱验证码重发间隔为 90 秒，前端倒计时和后端限流同时生效。密码仍须至少 8 位且含大小写字母，仅移除重复提示句。
- 注册成功的绿色提示框和「记住下次登录」30 天功能保留。

## 验证边界

后端验证使用隔离数据库，覆盖用户名迁移、用户名/邮箱登录、90 秒限流和三档权限的真实 LangGraph 暂停/恢复。模型和外部服务响应在自动测试中模拟，不调用用户的真实模型、SMTP 或生产验证码。

打包桌面另行验证实际 Electron 启动、普通账号首页、记住登录与临时登录的重启行为，以及中英文选择持久化。
