# 今日地图

Dev 与 Client 均支持自动将任务和日程中的地点标记到高德地图。

## 使用

1. 在清单设置中启用「地图模式」。点击语言按钮右侧的地图图标。
2. 在地图设置填写自己的高德 Web JS API Key、安全密钥和 Web Service Key，并设置默认城市。不同账号及发行版分别保存配置。
3. 打开地图后，系统自动解析今日安排的地点字段；没有地点字段时，尝试从标题、备注中的明确地点描述提取关键词。无需选择建筑。
4. 地点内容改变后自动重新定位。同坐标安排合并显示，可打开安排详情或使用可选的「校正地点」。

例如「去某大学图书馆自习」或备注中的「地点：某市国际金融中心」。教室号保留在任务、地图列表及详情中，搜索时只使用建筑关键词。「教学大楼214室」按教学楼搜索；校园中的实验楼教室编码按实验楼搜索。标记表示建筑位置，不表示室内教室坐标。

## 识别范围

- 仅展示启用地图模式清单中的今日有时间任务和日程。跨午夜及全天安排按设备时区计算；排除取消项、笔记和无时间任务。
- 自动识别采用本地规则和高德地点搜索，不是任意自然语言理解。线上会议、模糊描述、同名建筑和未收录建筑会显示原因，不随意选择其他地点。
- 可匹配建筑名称及地址，兼容教学楼/教学大楼等表达。搜索不持有日程锁，保存前复核安排及地图版本，防止旧响应覆盖新内容。
- 失败结果按内容和配置缓存；规则升级使旧缓存失效。可用「重新识别地点」主动重试。同一服务凭据的搜索请求受到频率限制。

## 地图与设备位置

地图跟随应用主题。可拖动顶栏移动浮窗、拖动分隔条调整左右宽度。布局偏好按本机账号保存。

打开地图后可读取一次设备位置并显示附近区域；「我的位置」重新请求。桌面版使用 Windows 定位服务，浏览器使用浏览器定位权限。设备坐标经高德转换为 GCJ-02；不持续追踪，也不保存定位历史。用户已经移动地图后，迟到的定位结果不改变其当前视图。定位失败时仍可查看任务地点。

## 数据与安全

- 地点标记是本机账号内的补充数据，不改变原任务文本、外部日历版本或同步状态，支持只读日历。
- 标题和备注的地点词语在本地提取。地点查询发送提取后的关键词、城市和必要的服务凭据；设备坐标转换会发送本次坐标。高德负责地图底图与其 SDK 请求。
- 服务 Key 和安全密钥保留在后端；JS Key 按 SDK 要求用于加载。配置字段留空保留原有密钥。
- 高德安全代理采用根路径 `/_AMapService`，校验账号、跨站来源并限制固定上游；旧 API 路径保留兼容。代理响应不缓存。
- 高德 SDK 属于外部脚本，并要求当前 CSP 允许 `unsafe-eval`。这扩大了对第三方脚本的信任；应用仍禁止内联脚本，Electron 保留沙箱和上下文隔离。

管理员可通过 `.env` 配置 `AMAP_JS_KEY`、`AMAP_SECURITY_JS_CODE`、`AMAP_WEB_KEY`；普通账号和 Client 在界面配置自己的凭据。底图 Key 与地点搜索的 Web Service Key 不可互相替代。

配置依据：[高德安全密钥](https://developer.amap.com/api/javascript-api-v2/guide/abc/jscode)、[地点搜索](https://developer.amap.com/api/webservice/guide/api/newpoisearch)。

验证与发布范围见 [v0.2.1 安全审计](SECURITY-AUDIT-2026-09-29.md)。
