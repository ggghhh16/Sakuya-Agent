# Sakuya 顶栏与规划面板更新（2026-09-27）

交付目录 `release-ui-v4/win-unpacked`，后端协议仍为 6。退出旧版窗口和托盘程序后，从项目根目录 `Sakuya Desktop.lnk` 启动。保留已有工作区数据和桌面配置。

- 恢复独立的 32px 顶栏，左侧显示线条图标和 Sakuya，右侧使用原生扁平窗口按钮。空白区域支持拖动，窗口按钮支持最小化、最大化/还原及关闭。
- 顶栏与界面使用相同的深浅主题颜色；应用恢复保存的主题时同步更新原生窗口按钮背景和文字色。主题 IPC 只接受 dark/light，并限制为本机应用主框架。
- 图标改为单色线条画，保留女仆发箍、短发和双辫特征，替换网页、窗口、托盘和 EXE 图标。
- 任务清单和日历的“我的规划”默认隐藏，点击工具栏同名按钮在右侧展开，再点收起；刷新或切换任务/日历视图后默认收起。收起后主区域使用释放出的宽度。
- 修复侧栏“所有任务”按钮因 flex 扩展占满高度的问题。
