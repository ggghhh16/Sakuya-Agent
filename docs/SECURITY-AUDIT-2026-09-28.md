# v0.2.0 安全审查与发布验证

审查日期：2026-09-28。覆盖新增聊天流式输出、任务引用、日历与任务交互、OAuth、独立窗口，以及发布文件、本地访问权限和生成文件残留。上一轮修复见 [2026-09-27 记录](SECURITY-AUDIT.md)。这是一轮源码审查和定向验证，不代表没有其他漏洞。

## 本轮确认并修复的问题

| 问题 | 触发条件与影响 | 修复 |
| --- | --- | --- |
| 只读清单写入校验不完整 | 直接调用 API/MCP 可向只读清单新建、移动条目；导入后权限变化也可能留下待同步修改。外部服务仍有自己的权限校验，并非获得外部写权限 | 新建、编辑、删除、恢复及保留本地冲突操作统一检查条目、当前清单与原同步清单；同步不向只读来源推送 |
| 断开连接可能被并发授权/刷新覆盖 | 网络请求未结束时断开，稍后的响应可能重新保存令牌；取消授权后 PKCE verifier 仍残留 | 凭据变更、授权交换、请求与断开共用可重入锁；断开返回后不保留旧请求写回的令牌；取消、配置变更、令牌替换和断开均清理授权临时字段 |
| 流式响应没有资源上限 | 异常上游可连续发送文本、工具参数或不换行的数据，占用内存与存储 | 解码后流量上限 2 MB、单行 256 KiB、处理期限 300 秒、工具调用索引限 0–127；保留取消检查和逐块渲染。网络读取另受 HTTP 超时约束 |
| 桌面重定向未独立限制 | 同源页面通过 HTTP 重定向把主窗口导航到外部来源；现有 Node/IPC 隔离仍生效 | 主窗口和独立窗口同时限制 `will-navigate` 与主 frame 的 `will-redirect`，不自动外开服务器重定向；保留验证 iframe。参见 [Electron 导航事件文档](https://www.electronjs.org/docs/latest/api/web-contents#event-will-redirect) |
| OAuth 文件与暂存区存在发布扫描盲区 | Google 应用配置的 secret 没有常见 API key 前缀；工作文件已清理而暂存内容仍含密钥 | 加入应用 OAuth 配置实际值比对、OAuth 文件名阻断、Git index 内容扫描、忽略规则和回归测试；扫描只报告文件与规则，不输出密钥 |
| 开发访问日志可能留下授权查询参数 | 开发 Uvicorn 访问日志记录 OAuth callback 的 code/state | 开发环境也关闭访问日志；生产打包服务原本已关闭 |

## 本地残留与权限

- 复核 `.env`、`.data`、私有恢复备份与桌面用户配置的 Windows ACL；未发现普通其他用户的 Allow 授权。发布资产暂存目录原权限过宽，已限制为当前用户、SYSTEM、Administrators。
- 经用户明确确认，删除 7 个未使用旧构建目录和 42 个隔离测试目录，共 3,810,631,716 字节。逐项检查绝对路径、进程占用与 reparse point 后删除。
- 保留正在运行的旧程序、真实用户工作区、私有备份、开发依赖、其他任务的审查资料，以及本轮验证证据。凭据受文件权限保护，不等同于加密存储。
- 发布只取构建白名单文件；不包含 `.env`、账号、模型密钥、OAuth 用户令牌、数据库、测试截图、备份或本机用户目录。

## 验证范围

- 后端：权限、账号隔离、OAuth 单次 state/临时字段清理、断开与令牌交换并发、只读 API/MCP/同步、SSE 限额和 UTF-8 分片，以及发布扫描回归。
- 前端：类型检查、生产构建和浏览器交互回归。旧模型测试服务改为实际 SSE 协议；聊天记录拖动测试使用独立普通账号，避免共用管理员历史导致目标滚出可见区域；额外修复未编辑的空白日程草稿无法点击外部关闭的问题。
- 打包桌面：CSP 阻止内联脚本、renderer 无 Node、匿名请求 401、伪造转发头仍触发 429、超限分块请求 413、隔离账号真实 worker 演示任务完成；全天栏、任务引用等交互单独验证。
- 依赖：npm 公告扫描及 Python 锁定/已安装依赖公告扫描。结果仅反映扫描时已公开公告。
- 分发：检查工作文件、实际暂存内容、可达 Git 历史、ASAR、物理包文件及解压后的 PyInstaller 应用代码；生成安装包 SHA-256。安装包内 220 个文件逐一与已验证程序比对，哈希全部一致；未在当前用户环境执行安装/卸载覆盖测试。

真实 Google/滴答授权、SMTP、Cloudflare 人工验证和付费模型调用未在本轮外发测试；相关网络协议使用隔离测试替身。安装包尚未代码签名。发布结果及精确测试数量见 v0.2.0 Release 说明。
