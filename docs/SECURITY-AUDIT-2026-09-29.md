# v0.2.1 安全与本地残留审计

审计日期：2026-09-29。覆盖今日地图、地点自动识别、设备定位、Dev/Client 隔离、发布扫描及两个 Windows 安装器。结果是本轮源码检查和实测证据，不代表不存在其他漏洞。历史记录见 [v0.2.0 审计](SECURITY-AUDIT-2026-09-28.md)和 [Client 首次发行验证](CLIENT-RELEASE-VALIDATION.md)。

## 本轮修复

| 问题 | 处理及验证 |
| --- | --- |
| 发布扫描未完整覆盖 Client 凭据来源 | 纳入 Client 数据目录、两版自定义数据/桌面目录与环境文件、用户级环境变量、账号子目录、OAuth 与地图密钥；被环境变量覆盖的旧密钥仍参与比对。阻断 `.data-*`、`dist-*` 等生成目录，测试验证实际 Git 暂存内容且不打印密钥 |
| 异常消息遗漏地图凭据脱敏 | 将当前账号保存的 JS Key、Web Key、安全密钥加入脱敏；回归检查密钥不出现在结果中 |
| 无登录 Client 的地图 GET/JSONP 可被外站触发 | 地图 API、根代理及兼容代理拒绝 `Sec-Fetch-Site: cross-site`，保留 Origin、Host、账号和写入请求检查；覆盖无 Origin 的跨站子资源请求 |
| 上游地点坐标为 null 导致异常 | 忽略非字符串、无效及越界坐标；有有效坐标但缺少 POI ID 的结果仍可使用 |
| 地图代理路径不符合 SDK 要求，反复弹出提示 | 代理使用根路径 `/_AMapService`，保留旧路径兼容。上游仅允许固定的初始化、样式和坐标转换端点，不接受任意目标 URL；打包程序真实高德测试无弹窗 |

自动识别只把提取后的地点/建筑关键词与城市交给地点搜索，不发送整条安排。原地点、教室号及任务标题备注保留；同名歧义或证据不足时不自动落到无关建筑。地图注释不修改外部同步版本，迟到结果不能覆盖用户后来修改的地点。设备坐标由固定脚本获取，限制调用来源、并发、输出长度和超时，不接收 renderer 自定义命令。

## 本地残留与发布内容

- 复核实际用户的 `.env`、数据、私有备份、两版发布目录的 Windows ACL，未发现普通其他用户的 Allow 权限；凭据没有因此变成加密存储。
- 本地仍有历史构建、隔离测试资料与恢复备份。保留这些资料以及真实工作区，本轮没有删除用户数据或旧构建；它们不进入 Git 暂存区或安装包。
- 高德实测使用独立测试账号，不复制真实任务，不采集真实设备坐标。测试结束清除临时 `map_secret`，并复查历史实测目录没有遗留该凭据记录。
- 检查工作文件、实际 Git index、可达 Git 历史、ASAR、物理包文件和解压后的 PyInstaller 应用代码。按密钥模式及本机已配置凭据实际值比对，未发现命中；扫描覆盖范围不等于能识别所有未知格式秘密。
- 本轮两版各自重新构建，不复用旧版 Dev 安装器。两个安装器各解出 221 个文件，与对应已扫描的 `win-unpacked` 逐文件 SHA-256 一致。发布文件仅为安装器及各自 `SHA256SUMS.txt`，不附本地运行日志或测试截图。

## 仍然存在的限制

- 高德 SDK 是在 renderer 执行的第三方代码，并需要 CSP 的 `unsafe-eval`；这扩大了对地图供应商的信任。内联脚本仍禁止，Electron sandbox、context isolation 与导航限制保持开启。实测 SDK 的内联 JavaScript 和附加 CDN 检测请求仍有 CSP 拦截记录，未影响本轮地图渲染及交互；没有为消除日志继续放宽策略。
- 设备定位权限/精度依赖 Windows，本轮没有用真实坐标验证原生定位精度。室内教室定位及任意自然语言地点识别不在保证范围。
- 真实模型、SMTP、Turnstile 人工验证、Google/滴答授权没有在本轮重新调用；相关回归采用隔离账号或协议替身。
- 安装包尚未代码签名。本轮解包校验了安装器内容，没有在用户真实环境覆盖安装或卸载。两版账号/文件隔离不用于对抗已控制当前 Windows 用户的恶意进程。
