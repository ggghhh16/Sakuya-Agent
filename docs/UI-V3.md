# Sakuya 界面更新（2026-09-27）

交付目录 `release-ui-v3/win-unpacked`，后端协议 6。退出旧版后通过项目根目录快捷方式启动，继续使用既有账号数据和桌面配置目录。

- 两侧竖线与各自外侧的整条边缘区域均可触发；左侧悬停打开聊天记录时，离开列表自动收起。顶栏按钮点击打开则保持展开，支持 Escape 和关闭按钮。
- 输入框仅保留一行工具栏：＋、权限、上下文环、模型、发送。功能选择与运行选项合并到＋菜单，闪电图标移除，思考级别标题使用浅色文字。
- 上下文环是估算值：按后端保留的同模式最近 12 轮、每条 4,000 字符截断、当前请求/草稿，加上系统与工具描述的估算开销计算。不是供应商实时返回的精确 token 数，也不代表自动压缩。默认容量未知时明确按 32K 估算；模型设置可填写供应商规定的真实容量。
- 「我的规划」位于任务清单和日历区域右侧。时间块编辑器改为独立圆角浮窗，表面 90% 不透明、10% 透明，使用 12px 背景模糊；可滚动、保存、取消及 Escape 关闭。
- 英文标题和正文使用与 Claude 阅读风格相近的 Source Serif 4；控件采用无衬线字体。它是开源近似字体，不是 Claude 的专有字体。字体随应用打包，可离线使用。[Adobe 字体仓库](https://github.com/adobe-fonts/source-serif)，许可证保存在 `public/fonts/LICENSE-SourceSerif.md`。
- 窗口、网页标题统一为 Sakuya。桌面使用 Electron 原生 Window Controls Overlay，隐藏独立标题栏，在页面顶栏保留原生最小化、最大化/还原及关闭按钮；空白顶栏可拖动。[Electron 官方说明](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)。
- 原创咲夜简笔头像为 `public/sakuya.svg`，带银色双辫、女仆发箍与钟表元素；生成多尺寸 ICO，用于 EXE、窗口、托盘及网页图标。`scripts/build-icon.mjs` 可重新生成，打包后由 `scripts/after-pack.cjs` 写入 EXE 图标与标题元数据。
